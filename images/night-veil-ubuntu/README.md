Night Veil Virtual Cell image: `desktop-ubuntu` plus an OpenVPN client, Tor, Tor Browser and
kill-switch firewall rules, attested before the Cell is ever reported READY. This is the highest
Comb Shield tier (a Cell's security posture: Meadow, Propolis or Night Veil) and is always torn
down, never Overwintered (kept dormant for later reuse). Populated in phase 6.
