# observation-web/src/landing_board

TypeScript types generated from `docs/entrance/openapi.json`, the committed OpenAPI contract for
the Landing Board (the Hive's versioned public API), plus the one client module that uses them for
login, signed requests, live streams and push (`client/`). `types.ts` is generated by
`pnpm generate`, never hand-edited, and `pnpm generate:check` (run in CI) fails when it no longer
matches the document. `call_types.ts` derives each request's and response's shape from the
generated types, so no Landing Board shape is written by hand.
