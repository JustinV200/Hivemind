# observation-web/src/landing_board

TypeScript types generated from `docs/entrance/openapi.json`, the committed OpenAPI contract for
the Landing Board (the Hive's versioned public API), plus the one client module that uses them for
authentication, live streams and push. The generated types file is never hand-edited: CI
regenerates it from the committed document and fails on a diff. Built out in phase 12, alongside
the Hive Entrance (the Hive's gateway) from phase 10.
