# observation-web/src/styles

The Observation Hive's CSS. `tokens.css` holds every colour, size and space as custom properties
in both themes (`docs/observation/design.md` section 3); `base.css` the element defaults;
`shell.css` the layout at phone, tablet and desktop widths; `components.css` the badges, status
dot, gauge and notices; `thoughts.css` the Thoughts view. Components use tokens only.
