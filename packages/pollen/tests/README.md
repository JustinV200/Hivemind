# pollen tests

Tests for the pollen package: the Pollen Packet, the lightweight connector that runs on a device
the Hive borrows as a Real Cell. This tree has no fixed internal shape yet beyond `conftest.py`,
the test composition root; it fills in as `packages/pollen/src/pollen/` grows, starting in
phase 11 when the Swarm subsystem gives it something to enrol with.
